## Surprises & Discoveries


The current dependency is `beartype>=0.20,<0.23`. Tox and both CI workflows refer to 0.20–0.22, so changing only package metadata would make those jobs unsatisfiable. CPU runtime on exact rc0 already passed in isolated audit probes, but those probes bypassed the metadata conflict and do not establish normal installation.
